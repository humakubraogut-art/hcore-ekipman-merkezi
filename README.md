# H-CORE – 7 Ekipman Pilot

## GitHub Pages kurulumu
1. GitHub üzerinde **hcore-ekipman-merkezi** adlı **Public** depo oluşturun.
2. Bu paketin içindeki `index.html`, `data.json` ve `assets` klasörünü **deponun köküne** yükleyin. ZIP dosyasını doğrudan yüklemeyin.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Yayın adresi: https://humakubraogut-art.github.io/hcore-ekipman-merkezi/
5. QR kodları bu adresi hedefler. Depo adını farklı seçerseniz QR dosyaları yeniden üretilmelidir.

## İçerik
7 makine; Excel plaka sekmelerindeki özgün görseller ve bakım açıklamaları; ana listedeki filtre kayıtları; her makineye ayrı gerçek QR PNG.

## Kart yazdırma
Bir ekipman panelinden **16 × 8 cm QR kartını yazdır** ya da ana sayfadan toplu yazdır seçin. Yazdırma ölçeğini %100 yapın, üstbilgi/altbilgiyi kapatın.

## Veri güncelleme
Ekipman verileri `data.json` dosyasında tutulur. QR adresleri sabittir. Bu sürüm yalnızca görüntüleme ve kart yazdırma içindir; bakım kaydı girişi / yetkilendirme henüz yoktur.
